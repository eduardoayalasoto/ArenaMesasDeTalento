# Contexto del proyecto — EvaluacionesArena (2026-07-01)

## Stack

- Django 4.x · SQLite · Python · cp1252 (encoding del repo en Windows)
- HTMX (autosave, swaps, toggles sin recarga)
- Tailwind CSS (clases utilitarias, compiled via Django, no Node en runtime)
- Alpine.js (estado reactivo inline: `x-data`, `x-show`, `x-cloak`)
- simple_history (audit trail en modelos principales)
- Sin Node en producción; sin pytest configurado (pruebas manuales via servidor de desarrollo)

## Cómo correr el servidor

```powershell
python manage.py runserver
```

Servidor en `http://127.0.0.1:8000/`. No hay `npm run` ni build step activo.

## Convenciones clave del codebase

| Tema | Convención |
|---|---|
| Soft delete usuarios | `is_active=False` + `deleted_at=DateTimeField(null=True)` |
| `is_admin` | property = `is_superuser OR is_talento` |
| `is_director` | property en User |

| HTMX autosave | `hx-trigger="change"` en checkboxes; `@input.debounce.800ms` en textareas |

```python
class TalentSessionNote(models.Model):
    user = models.ForeignKey(User, on_delete=PROTECT, related_name="talent_notes")
    period = models.ForeignKey(Periodo, on_delete=PROTECT)
    fortalezas = models.TextField(blank=True)
    oportunidades = models.TextField(blank=True)
    scenario_actual = models.ManyToManyField(ScenarioOption, blank=True, related_name="notes_actual")
    scenario_s1 = models.ManyToManyField(ScenarioOption, blank=True, related_name="notes_s1")
    scenario_s2 = models.ManyToManyField(ScenarioOption, blank=True, related_name="notes_s2")
    created_by = models.ForeignKey(User, on_delete=PROTECT, related_name="talent_notes_created")
    updated_at = models.DateTimeField(auto_now=True)
    history = HistoricalRecords()

class FeedbackResponsible(models.Model):
    note = models.ForeignKey(TalentSessionNote, on_delete=CASCADE, related_name="responsables")
    user = models.ForeignKey(User, on_delete=PROTECT)
    is_primary = models.BooleanField(default=False)
    class Meta:
        constraints = [UniqueConstraint(fields=["note", "user"], name="unique_note_user")]
```

## Vistas Mesa de Talento — lógica clave

`talent_person` en `apps/dashboards/views.py`:
- Acceso: `is_admin` (Talento/superuser) o `is_director`
- Llama `build_results(target, period)` — sobrescribe `ctx["feedback"]` con **todas** las evaluaciones (no solo submitted) para que Talento vea el feedback completo
- Hace `get_or_create` del `TalentSessionNote`
- Pasa `primary`, `secondaries`, `all_users` (excluye ya-asignados) al contexto
- Helper `_responsables_fragment()` re-renderiza el widget tras cada acción HTMX

### `_responsables_widget.html` — comportamiento actual

- Alpine: `x-data="{ editingPrimary: false, addingSecondary: false }"`
- **Principal**: muestra nombre + botones "cambiar" (toggle form) y "quitar" (HTMX remove)
- Form cambiar principal: `<select>` con `hx-trigger="change[this.value !== '']"` + `hx-include="closest form"` — auto-submit al seleccionar, sin botón Guardar. Ancho: `max-w-[16rem]`.
- **Secundarios**: cada uno con botón "quitar" (HTMX remove)
- "Agregar secundario": mismo patrón de select con auto-submit HTMX

## Gotchas / cosas no obvias

- **No usar `select_related("primary_evaluator")`** — es `@property`, no FK. Solo `select_related("project")`.
- **`build_results` filtra feedback a submitted=True** — en `talent_person` se sobrescribe con todas las evals.
- **Tailwind no tiene hot-reload** — cambios de clase requieren reiniciar servidor o tener el watcher activo.
- **Encoding cp1252** — cuidado con caracteres especiales en archivos nuevos.
- **`_open_period()`** — devuelve el único periodo abierto o `None`. Si hay más de uno, puede fallar silenciosamente.
- **HTMX `hx-swap="outerHTML"`** en el widget — reemplaza el `<div id="responsables-widget">` completo; Alpine reinicia a estado por defecto (editingPrimary: false) tras cada acción, lo cual es el comportamiento deseado.
- **`FeedbackResponsible.is_primary`** — hay UniqueConstraint `(note, user)`. Si el mismo usuario ya es secundario y se intenta poner como principal, fallará con IntegrityError (o viceversa). La vista debería manejar esto.
