Uso: {% include "components/_avatar.html" with user=user size=30 %} -- 1 letra, para un User real (get_full_name/username). {% include "components/_avatar.html" with name=person.full_name size=28 %} -- 2 letras, para cualquier otro nombre suelto (ej. Person, que no tiene get_full_name()) -- pedido explícito del usuario, 2026-09-23: "siempre que se seleccione una persona, usar avatar con dos letras". Props: user: instancia de User (prioridad sobre `name` si ambos vienen) name: string con el nombre completo -- se usan sus iniciales (2 letras) size: tamaño en px del círculo (default 32) id: id HTML opcional para el círculo interior (para actualizarlo vía JS/Alpine) GOTCHA (encontrado 2026-09-25, ficha de Deal): `{% include ... with name=... %}` SIN `only` sigue exponiendo el `user` de la request (context processor de auth) a este parcial -- `{% if user %}` lo toma aunque el caller solo haya pasado `name`, mostrando las iniciales de quien tiene la sesión abierta en vez de las de `name`. Si el caller no quiere mostrar al usuario logueado, pasa `user=None` explícito junto con `name=...`. {% endcomment %}
