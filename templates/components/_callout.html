{% comment %} Callout (aviso en línea) -- SIEMPRE con ícono Lucide según el tono (DESIGN_SYSTEM.md § 6). No se incluye directo: se usa el tag de bloque, que admite contenido rico (enlaces, botones): {% load callout_tags %} {% callout "info" %}Texto del aviso.{% endcallout %} {% callout "warning" title="Te pidieron ajustes" %}...{% endcallout %} {% callout "success" icon="lock" %}Evaluación cerrada...{% endcallout %} Tonos -> ícono por defecto (semántico, no decorativo): info -> info (contexto, instrucciones, solo lectura) success -> circle-check (completado, cerrado con éxito) warning -> triangle-alert (requiere atención o acción) error -> circle-alert (falló, bloqueado) neutral -> info (nota secundaria) `icon` lo sobrescribe solo cuando el estado es más específico (lock, megaphone para anuncios). Con botón de acción: envolver el cuerpo en `
` y darle `ml-auto` al botón. {% endcomment %}
