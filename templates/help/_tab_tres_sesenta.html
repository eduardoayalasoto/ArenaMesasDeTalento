{% load callout_tags help_tags %} {% callout "neutral" title="Qué es la 360 al owner" %} El equipo de un proyecto califica a su owner con un cuestionario de dimensiones (liderazgo, planificación, cliente…). Es informativa: no cuenta para Ownership, Entrega de Valor, Impacto Arena ni la calificación final; da un índice de 1 a 4 con su banda. Solo existe en los proyectos donde Talento activó la casilla «Activar evaluación 360 al owner». {% endcallout %} {% if h.to_answer_360 %} {% help_step n=1 icon="pencil-line" title="Tienes 360 por responder" %} En Mesa de Talento → Evaluaciones 360 → Por responder: {% for r in h.to_answer_360 %}{% if r.pending %}{{ r.project.name }} (evalúas a {{ r.project.owner.full_name }}){% if not forloop.last %}, {% endif %}{% endif %}{% endfor %}. Tu borrador se guarda solo; al enviar ya no puedes cambiarla. Quien recibe el resultado no ve quién respondió qué. {% end_help_step %} {% endif %} {% if h.owner_360 %} {% help_step n=2 icon="gauge" title="Lo que tu equipo dijo de ti" %} En Evaluaciones 360 → Lo que mi equipo dijo de mí ves tu score por proyecto ({% for p in h.owner_360 %}{{ p.name }}{% if not forloop.last %}, {% endif %}{% endfor %}), el desglose por dimensión y los comentarios, sin nombres. Se actualiza en vivo; con una sola respuesta el score es esa calificación y con varias, el promedio. {% end_help_step %} {% endif %} {% if h.profile.admin or h.profile.director %} {% help_step n=3 icon="list-checks" title="Seguimiento" %} Evaluaciones 360 → Seguimiento: por proyecto ves cuántos respondieron, quién falta y el score. Para activar la 360 en un proyecto: Administración → Proyectos → editar → «Activar evaluación 360 al owner». {% end_help_step %} {% endif %} {% if h.profile.admin %} {% help_step n=4 icon="clipboard-check" title="Cuestionario 360" %} Se crea en Modelo de evaluación → Cuestionarios → + Nuevo cuestionario → tipo «360 al owner»: cada sección es una dimensión con su ponderación (deben sumar 100%; una en 0% se califica pero no pesa). {% end_help_step %} {% endif %}
